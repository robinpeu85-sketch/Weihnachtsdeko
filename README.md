# Weihnachtsdeko aus dem 3D-Drucker

Bestellseite für selbst gedruckte Weihnachtsdeko unter Kollegen.

- Die Seite zeigt Modelle, Farben und wie viele Stück das vorhandene Filament noch hergibt.
- Bestellungen und Bestand liegen in einer Google Tabelle, angebunden über ein Google-Apps-Script.
- Bestellschluss: 10.12.
